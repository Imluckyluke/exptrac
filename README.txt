راهنمای گرفتن APK
==================

1. یک ریپازیتوری جدید در GitHub بساز (مثلاً به نام ExpenseTracker)، Public یا Private مهم نیست.

2. تمام فایل‌ها و پوشه‌های داخل این zip را (با همین ساختار پوشه‌ها) در همان ریپو آپلود کن.
   - از گوشی: در صفحه ریپو روی "Add file" > "Upload files" بزن، فایل‌ها را بکش و رها کن، Commit بزن.
   - نکته مهم: پوشه .github باید دقیقاً همینطور با همین اسم آپلود شود (این پوشه مخفی نیست، در گیت‌هاب دیده می‌شود).

3. برو به تب Actions بالای صفحه ریپو. یک workflow به اسم "Build APK" می‌بینی.
   اگر خودش اجرا نشد، روی "Run workflow" بزن.

4. صبر کن (حدود ۳-۵ دقیقه) تا build تمام شود (علامت سبز).

5. روی همان اجرای build کلیک کن، پایین صفحه بخش "Artifacts" را ببین،
   فایل app-debug-apk را دانلود کن. یک zip است که داخلش app-debug.apk هست.

6. فایل apk را روی گوشی منتقل کن (یا مستقیم با گوشی دانلودش کن)،
   نصب کن (باید گزینه "نصب از منابع ناشناس" را برای مرورگر/فایل‌منیجر فعال کنی).

توضیح اپ:
- تاریخ شمسی امروز را نشان می‌دهد، با دکمه قبلی/بعدی می‌توانی روز را عوض کنی.
- برای هر روز می‌توانی اقلام هزینه و مبلغ را وارد و اضافه کنی.
- جمع کل هر روز پایین صفحه نمایش داده می‌شود.
- اطلاعات به صورت محلی روی گوشی ذخیره می‌شود (بدون نیاز به اینترنت).
